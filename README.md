# MoLiNas Intelligence Dashboard & Executive Ecosystem Portal

Portal eksekutif dan database intelijen kemitraan industri kendaraan listrik nasional (**MoLiNas**) berbasis data strategis 2026–2035.

## 🚀 Fitur Utama

- **Otorisasi Akses Khusus**: Dilengkapi halaman login gateway berbasis *Security Access Key* rahasia (`login.html`) untuk membatasi akses hanya bagi pihak berwenang (BOD, PMO, dan mitra resmi).
- **Tipografi Bersih (Standard Arial)**: Desain korporat institusional yang elegan, terstruktur rapi ala format pelaporan PT Len Industri / BUMN / Danantara, bebas dari distorsi visual (*no AI slop*).
- **Dukungan Dark & Bright Mode**: Saklar mode tampilan (gelap/terang) interaktif dengan kontras tinggi yang tersimpan otomatis di browser.
- **Ringkasan Eksekutif & Matriks Prioritas Scatter**: Pemetaan kuadran *Impact vs Urgency/Criticality* untuk 32 stakeholder (P1 Gatekeeper, P2 Scale Enabler, P3 Support).
- **Direktori Stakeholders & Modal Profil Dossier**: Data komprehensif 32 pemangku kepentingan lengkap dengan skor bobot, domain rantai nilai, penanggung jawab BOD, dan agenda tindak lanjut.
- **Matriks Kebijakan Strategis (12 Pilar Revisi Perpres)**: Analisis komparasi regulasi eksisting (Perpres 55/2019 vs Perpres 79/2023), pemetaan gap 2026–2035, usulan revisi, milestone TKDN, dan alokasi R&D.
- **Eksplorer Regulasi & Standar**: Katalog 204 ketentuan perundang-undangan (UU, PP, Permenperin, Permenhub, Permen ESDM, SNI) dengan fitur pencarian instan.
- **Market & Media Intelligence**: Kurasi 130 artikel intelijen pasar terbagi dalam segmen MoLiNas, Pasar Lokal, dan Global.
- **Direktori PIC Kontak**: 10 kontak eksekutif mitra kunci dengan fitur 1-klik salin nomor/email dan ekspor kontak.
- **Manajemen Data Dinamis**: Fitur tambah data langsung dari antarmuka (*Add Data Modal*) yang tersimpan di `localStorage` dan opsi *Ekspor ke CSV*.
